# scripts/

Utility scripts for the AxioMedica monorepo.

| Script                      | Purpose                                      |
|-----------------------------|----------------------------------------------|
| `validate_contracts.sh`     | Run both JS and Python contract validators   |
| `setup_backend.sh`          | Bootstrap backend Python venv + deps         |
| `setup_ml.sh`               | Bootstrap ML Python venv + deps              |

Run from the repo root:
```bash
bash scripts/validate_contracts.sh
```
